# 制作过程 v0.5.3-preview

本版消除“检索不到资料就无法出片”的最后一段死胡同：找不到可核对的公开网页时，直接以 AI 初步回答为唯一内容基础制作视频（证据层明确标注未核实）；找到资料则照常摘录。同时修复了旧失败快照被永久复用、模板降级读取过期数据两个真实缺陷。

## 本版修复

- AI 初步回答降级制片（用户决策）：研究层 0 来源且非演示模式时，千问“问题初解”成为唯一来源 S1，标题与说明明确写“AI初步解释（未找到可核对网页，内容未经外部来源核实）”；生成提示硬性要求只使用 S1 原文、不得添加新事实数字或例子；S1 引文仍受逐字定位与无来源数字 blocker 约束。找到资料时正常进入原文摘录流程，不降级。
- 0 来源快照强制重检索：项目已有研究记录但来源为空时，重跑视为“一次失败尝试”而非结论，重新检索（新后备目录与关键词调整会生效）；不再复用死胡同结果。
- 模板降级读取本次快照：确定性模板取“问题初解”时优先使用本次研究快照，避免旧记录过期数据导致模板校验失败、任务整体 failed。
- 检索扩大：science 域新增 NASA Space Place“天空为什么是蓝色”后备入口（天空/蓝色/散射/夕阳四术语映射）；搜索命中 URL 因跟踪参数被安全规则拒绝时，剥离 query 重试一次。
- 前端降级 UI：基于 AI 初步解释出片时不再显示红色错误块，改为温和提示并保留“复制问题，使用新版重新检索”入口。
