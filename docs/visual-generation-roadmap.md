# 图像、海报、视频与自动修订路线

## 最终产品形态

同一个科学传播任务共用一组可追溯事实卡，用户可选择生成：

1. 可编辑 SVG 信息图海报；
2. 包含 AI 科学插图的图片海报；
3. 动态海报或短视频；
4. 分镜脚本、字幕、旁白和来源卡；
5. 根据自动质检或人类反馈局部重生的新版本。

## 统一数据链

`ScienceBrief -> EvidenceClaim -> VisualAsset -> PosterLayout -> VideoScene -> ReviewIssue -> Revision`

- `ScienceBrief`：主题、受众、传播场景和输出媒介。
- `EvidenceClaim`：科学事实、来源编号、证据摘录、条件边界和检索分数。
- `VisualAsset`：插图/图标/背景/图表的生成提示、模型、尺寸、版本、来源事实和文件。
- `PosterLayout`：图层、文本、资产位置、配色、阅读顺序和导出规格。
- `VideoScene`：分镜时长、画面提示、镜头运动、旁白、字幕和对应事实。
- `ReviewIssue`：事实、因果、数值、文字可读性、构图、安全和版权问题。
- `Revision`：修改指令、修改范围、前后版本、触发者和验证结果。

## 图片海报流程

1. RAG 只输出达到证据阈值的事实卡。
2. Qwen 将事实卡转换为插图简报，区分“必须准确”与“可艺术化”元素。
3. 图像模型生成无文字或少文字的视觉资产，一次最多生成少量候选。
4. 应用使用 SVG/HTML 程序化排版叠加标题、数据、标注和来源，避免让生图模型绘制关键文字。
5. 多模态模型对成品做科学一致性、文字可读性和构图检查。
6. 只重生失败的图层或局部区域，不重做整张海报。

## 视频流程

1. 从同一组事实卡生成 3–6 个分镜。
2. 先生成分镜图和字幕草案，通过人工审核后再调用视频模型。
3. 视频模型只生成镜头画面，旁白、字幕、来源卡和转场由应用合成。
4. 对关键帧执行多模态检查，对失真对象、时间顺序或错误标注定位到具体分镜。
5. 仅重生有问题的分镜，然后重新合成。

## 自动修订闭环

`Generate -> Inspect -> Classify -> Patch -> Re-inspect -> Human approve`

- 最多自动修订 2 轮，避免无限循环和费用失控。
- 事实、因果或数值问题不允许模型自行猜测，必须回到证据卡或请求补充资料。
- 布局、色彩、裁切和局部绘图可自动修改。
- 每一轮保留原图、问题列表、修改指令、新图和质检得分。

## 成本与赛事证据

- 调用前估算图片数、视频秒数和费用，用户确认后再执行高成本任务。
- 继续执行累计70元暂停线和100元上限。
- 提交证据包包含模型系列、调用时间、脱敏request_id、输入事实ID、自动评审、人工修订和前后版对比。
