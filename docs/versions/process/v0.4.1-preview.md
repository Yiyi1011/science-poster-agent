# 制作过程 v0.4.1-preview

## 本版解决的实际故障

用户看到“脚本已通过但没有视频”。检查保存记录发现同一项目连续三次停在卡通规划结构校验：千问返回了对象库外的`brain/chat/spark`等装饰图标，Pydantic拒绝整个计划。另一类基础问题能取得脚本前解释，却可能因搜索短暂失败或模型多选一段原文而显示0来源。

## 修复

- 卡通规划先做只限`icon`字段的确定性兼容映射，标签、关系、字幕和科学陈述均不改；前端显示原值、替换值与原因。
- 其余JSON结构错误最多交给千问修复一次；失败字段和旧任务继续保留，不把失败伪装成成功，也不无限重试收费。
- 资料筛选改为选择后台生成的段落ID，彻底避免模型复制原句时因空格/标点细差导致“伪造引文”误判。
- MDN、AWS等官方概念入口独立于搜索插件：搜索暂时不可用时仍实际访问HTML并逐段核验，不把目录文字当证据。
- 模型选择的原文超过900字时，确定性保留不超上限的前缀段落并记录裁剪；不存在的段落ID仍整项拒绝。

## 真实验证

- 项目“AI为什么能说得流畅，却仍可能答错？”：旧三次结构失败原样保留；新版生成6镜、68秒、1280×720、20fps卡通MP4，含Qwen旁白和字幕。4处机械图标兼容留痕，Qwen-VL六镜均给出通过；这仍不是专家科学终审。
- 只读浏览器验证实际加载并播放视频，检查MP4范围下载、6个候选入口、修改记录、选做海报和390px布局，JavaScript错误为0。
- 新建“API是什么？普通人怎么理解它的作用？”：实际读取MDN与AWS两份官方正文，来源摘录非模型改写；生成8镜脚本，2版、3处自动修改，最终无模型阻断项。本轮没有为API再次生成视频，不能把脚本成功写成第二条成片。
- 147项后端测试与前端生产构建通过。测试覆盖搜索异常后备、段落ID防伪、超长选择裁剪和未知卡通图标兼容。

## 边界与费用

视频是“千问规划＋程序卡通动作＋Qwen-VL检查＋Qwen TTS＋本地合成”，不是Wan或其他视频大模型直接生成。自动检查不能替代完整试听、领域专家复核或公众测试。本机台账累计原价估算约9.875687元，不是阿里云实际扣款，搜索插件等项目仍以账单为准；远低于约定70元暂停线。
