# 跨主题工作台 v0.2.0

## 这一版实际完成了什么

首页为跨主题工作台。旧版海报原型保留在`/?view=legacy`，太阳分镜在`/?view=storyboard`，已认可的太阳有声视频没有覆盖。

每次创作保存独立项目、资料快照和版本。支持粘贴文本，或导入UTF-8 TXT/Markdown（单文件100KB内、正文15000字内；最多6份、合计24000字）。链接仅作来源标注，不自动抓取；PDF/Word请先复制相关正文。无资料会停止，不会默认检索太阳知识库。不声称已经覆盖全部学科或实现自主全网查证。

资料输入后发送至用户配置的百炼空间。不要上传密钥、账号凭证、私人学生记录或未经许可的全文。项目是本机单用户数据；当前没有多人权限隔离。

## 使用顺序

1. 点击示例或填写自己的问题、受众和资料。两个示例来自NIST与IES公开资料的中文整理摘要，不冒充原文翻译。
2. 点击“生成作品并自动审核”。可以观察真实执行阶段：生成、原文定位、审核改写、复检。
3. “图解海报”显示可编辑概念图，点击可放大；“独立分镜”显示另一套面向公众的旁白和画面动作。动态预演只有通用角色与文字，不是已完成的通用卡通视频。
4. “自动改进”先显示修改数量；展开才看修改前后。复检说明默认收起，避免界面冗长。
5. 可补充自己的建议，再执行自动审核修订。更换资料时复制为新项目，不能偷偷改变旧稿的证据来源。
6. 刷新后从“打开已保存项目”恢复。版本页可查看初稿、修改稿和对应海报。
7. “导出草稿包”包含最新版SVG、离线展示HTML、分镜JSON、完整项目/修订/调用记录、估算时间字幕SRT。导出包含自己的资料，分享前再检查授权与隐私。

## 自动修订的真实边界

- 第一阶段由千问生成事实卡、概念图规格和独立分镜，不是把海报逐字朗读。
- 程序逐条验证`source_id`存在且引文能在该来源正文中定位，验证分镜引用的事实编号存在。它**不证明引文支持该结论**，更不证明资料本身可靠。
- 千问进行语义审核并返回完整修订稿，再次定位引文并调用千问复检。
- 若复检还有问题，可进入第二轮，总共最多两轮，避免无限反复调用。仍有问题则停下交给人，不能宣称已经合格。
- 不通过的候选修改只记录为`proposed_changes`，不覆盖原稿。无内容变化时记录为审核版本，`changes`为空；不伪造修改量。
- 同一请求ID重试不会重新触发模型；并发操作/过期版本被阻止。中途失败保留已有稿件，不自动收费重试。
- 模型仍可能误判。真实测试中，第一次AI复检放过了“统计生成→没有理解”等过度推论，开发者补充审核意见后再次修改。该过程是开发者反馈，不是独立公众评测或专家通过。
- 输出统一标为“AI生成草稿，待人工终审”。当前尚未给通用海报做Qwen-VL像素级审核，也未生成通用MP4/旁白或任意主题的细致角色动画。

## 模型合规

核对日期：2026-08-31。依据[赛事官网](https://university.aliyun.com/action/tzbjbgs2026)及用户提供的方向2提交模板。基座使用千问，通过百炼调用；方向模板明确也包含Wan。本项目当前更保守地将配置限定为Qwen系列，不自动回退第三方模型。

| 环节 | 实际模型/方式 | 本版接入情况 |
|---|---|---|
| 跨主题生成、审核、修订、复检 | 百炼北京 `qwen-plus` | 已真实调用，按操作保存调用ID、模型、提示词版本/哈希及Token用量 |
| 图解排版 | 团队Python SVG渲染代码 | 已接入；不冒充文生图模型输出 |
| 图像生成 | `qwen-image-3.0` | 既有独立脚本，尚未接入新工作台按钮 |
| 图像理解 | `qwen3-vl-flash` | 既有独立脚本，尚未给新工作台做视觉闭环 |
| AI旁白 | `qwen-audio-3.0-tts-flash` | 太阳有声案例已使用；通用分镜尚未接入配音合成 |

接口配置必须是百炼北京HTTPS域名；服务端拒绝其它平台和模型系列。真实调用日志不记录Key。费用仅是本地价格假设下的估算，无法代替阿里云实际账单；70元暂停、100元实付上限不变。

## 封装版运行

源码开发使用Vite；封装版使用构建好的`frontend/dist`，仅运行一个Python服务，地址为`http://127.0.0.1:8000/`，不需要同时启动5173。

本机可双击`启动封装版.cmd`。启动器先检查已运行版本并复用，不会重复启动，不会盲目结束占用端口的进程；后台启动不额外弹出服务窗口。出错时保留控制台提示，日志位于`.local-logs/packaged.*.log`。

这是“预构建前端＋Python后端”的本地包，**不是免安装EXE**。新电脑仍需Python 3.11+及后端依赖：先在项目根目录创建`.venv`，安装`backend[dev,video]`；按交接教程创建自己的`.env`，建议先Mock。包里不含别人的Key、数据库、原始视频素材或云端知识库。

当前仅支持单个后端worker。不要增加`--workers`，因为启动恢复和任务队列按单进程设计。运行数据默认在`artifacts/studio.sqlite3`；设置`SCIENCE_POSTER_DATA_DIR`时使用该目录。云端必须挂载持久盘/数据库且完成鉴权限流后才能上线，不能把临时目录当唯一副本。

## 提交前仍需完成

方向2模板要求技术方案PPT/PDF不超过20页，而不是官网总说明的30页；演示视频如有不超过10分钟。需要设计源文件/高清图、科学资料来源、真实调用凭证、代表图与修正对比；程序作品需源码与运行说明。团队名称、报名表两页盖章截图等由参赛团队补齐。

下一阶段优先把新工作台的分镜连接至既有千问配音和视频合成，再补跨主题视觉素材与像素级复检；之后才是正式成品验收、提交文档和公网部署。不能把现在的动态分镜预演写成“通用卡通视频已完成”。

资料链接：[NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1)、[IES学习指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。模型结构化输出依据[百炼官方说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。
