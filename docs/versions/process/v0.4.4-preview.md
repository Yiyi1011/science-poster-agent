# 制作过程 v0.4.4-preview

本版是v0.4.3交接检查点的备份工具修正版。首次真实创建私有运行数据包时，SQLite事务已提交但连接未显式关闭，Windows在清理临时数据库时返回文件占用错误。源数据库和媒体没有被修改，失败目录已写入`FAILED.txt`，明确禁止用于恢复。

修复后使用`contextlib.closing`显式关闭源库、目标快照和完整性检查连接，并在关闭目标连接前提交。正式私有包只有同时满足以下条件才可交接：脚本正常退出、目录存在`manifest.json`、`contains_env=false`、`sqlite_integrity=ok`、ZIP SHA256复算一致、解压后找不到`.env`且快照数据库再次通过`PRAGMA integrity_check`。

字幕、视频、提示词和应用功能与v0.4.3相同：完整句字幕、长句同cue换行、Claude＋DeepSeek只作编程/审查、生产运行仍使用百炼Qwen。本版仍是制作过程版，不是最终发布。
