# 制作过程 v0.5.8-preview

本版是公网零配置发布候选，不是最终交付版，不创建 `final/` 标签。

## 目标变化

- 最终普通用户入口改为同源公网 Web 应用：打开网址即可提问和生成视频，不填写 API Key、不修改 `.env`、不安装 Python。
- 百炼 API Key、匿名会话签名密钥和费用配置只保存在阿里云函数计算环境变量中，不进入浏览器、GitHub、源码 ZIP 或桌面 EXE。
- Windows EXE 保留为制作方备用与本地回退版本，不再作为“任意设备免配置”的主交付物。

## 公网保护

- 浏览器首次访问自动获得签名的 HttpOnly/SameSite 匿名会话；项目按会话隔离，不同浏览器不能读取、下载或删除彼此项目。
- 创建项目、审核生成和独立制片分别设置透明时段额度；额度检查在付费任务预留前完成。
- 全局仅允许一个生成任务实际运行，并限制等待任务总数；避免多个公开访问同时堆积模型费用和内存占用。
- 公开模式只开放当前 Studio API、健康检查和公开配置；旧海报规划与太阳分镜接口关闭，不能绕过配额。
- 生产启动会检查：真实千问模式、北京 HTTPS 接口、服务端 Key、至少 32 位会话密钥、绝对持久目录及合法队列参数。缺失时拒绝启动，不以半配置状态上线。
- 原有本地费用台账暂停线继续生效；估算接近 70 元即停止新模型调用，真实账单仍以百炼控制台为准。

## 云端候选

- Docker 单 worker 监听 `0.0.0.0:9000`，Keep-Alive 设为 900 秒。
- 发布建议为 1 vCPU / 2 GB、10 GB 临时磁盘、NAS 挂载 `/data`、最大实例 1；答辩期间最小实例 1，结束后改为 0。
- 本机无 Docker，未伪称 Linux 镜像已构建；已用生产环境变量启动真实 FastAPI 服务，首页与健康检查为 200、真实模式状态正确、匿名 Cookie 生效、旧接口返回 404，且未触发百炼调用。
- Linux 镜像需在阿里云连接 GitHub 后由云端实际构建，再完成健康检查、NAS 持久化和一条真实视频验收。

## 验证

- 后端 203 项测试通过，包括会话签名防篡改、双浏览器项目隔离、原子额度、幂等重试不重复计额和旧接口关闭。
- TypeScript 与 Vite 生产构建通过。
- Dockerfile 与 Git 差异检查通过；Docker 实构建待云端。

## 提交材料边界

- 最终源代码另打 ZIP 上传夸克网盘，并在提交材料中同时给出 GitHub 仓库链接。
- ZIP 内含简要说明、代码地图、版本说明、依赖清单、测试说明和 SHA256；排除 `.env`、API Key、本地数据库、私人项目、日志及缓存。
- 最终云端验收、内容终审和提交文档视觉检查通过后，才创建 `final/v1.0.0`。
