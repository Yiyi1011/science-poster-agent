# 制作过程 v0.5.6-preview

本版是明日封装前的跨设备候选检查点，不是最终交付版。

## 本版改进

- 工作台右侧改为页面统一滚动，宽屏时左侧输入区粘性定位；移除嵌套长滚动条，390px 窄屏无横向溢出。
- 修复浅色提示框里的白字：错误文案改为深棕红字＋浅粉底，按钮保持深色高对比。
- 资料检索扩展到官方机构、高校、专业学会、博物馆和有编辑审核的权威科普站；首轮未选中时允许一次“部分支持”复查，引用仍须逐字定位原文。
- HTTPS 改用 `truststore` 读取 Windows、macOS 或 Linux 的系统原生证书库，不关闭证书或主机名校验，不写死本机 CA 路径。
- SQLite、视频、音频、字幕与媒体清单统一跟随 `SCIENCE_POSTER_DATA_DIR`；可将只读程序与可写用户数据分开。
- 本地启动预检增加数据目录可写性、`truststore`、macOS 与 Linux Noto CJK 字体路径；容器安装视频依赖、中文字体与系统 CA，以非 root 身份运行，数据持久化到 `/data`。

- 问题：“不同地方水的颜色为什么会不一样”，项目 `bcb58391-aecc-4c5b-8ff8-55fe32f1db3a`。
- 旧版状态：0 份原文，多次停在资料不足或画面检查。
- 新版结果：真实读取 NOAA 海水颜色页与 Science Learning Hub 水色/水质页，保存 2 份逐字摘录，证据缺口为空；生成 7 镜、68 秒卡通 MP4。
- 媒体独立检查：1280×720，音轨存在，15 个完整句字幕 cue，最后字幕于 67.428 秒结束，3 帧抽样可解码。
- 浏览器只读验收：实际加载并播放 MP4、Range 下载、证据页、桌面与 390px 手机布局通过，页面错误 0，验收未发起额外付费动作。
- 自动测试：194 项后端测试通过；TypeScript 和 Vite 生产构建通过。

## 便携性边界

- Windows 本机单端口启动已验证；当前主机未安装 Docker，因此容器定义只完成了代码/配置检查，明日封包前仍需在 Docker 或目标服务上做一次实际构建。
- 换设备时必须使用各自的百炼 Key，并需 Python 3.11+，或使用 Docker；源码包不嵌入 `.env`、私有数据库或运行时媒体。
- “任意问题”指合理的公众科普问题；政治敏感、高风险个人决策、明显危险或无法核实的内容仍会拒绝、降级或要求人工复核。
- 本版不创建 `final/` 标签；仍需完整试听水色成片、目标设备/容器构建和正式参赛材料检查。
