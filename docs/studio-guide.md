# 跨主题工作台 v0.4.2-preview（制作过程版）

## 这一版实际完成了什么

首页为跨主题工作台。旧版海报原型保留在`/?view=legacy`，太阳分镜在`/?view=storyboard`，已认可的太阳有声视频没有覆盖。

每次创作保存独立项目、资料快照和版本。新项目默认只需问题，系统通过百炼搜索候选、读取允许站点的公开HTML并选择可逐字定位的摘录；没有合适原文会停止。不是全网全文论文数据库，来源缺口仍可能需要人补料。已存失败检索不会重复收费搜索，换问法时新建项目。

手动资料为可选项：支持粘贴文本，或导入UTF-8 TXT/Markdown（单文件100KB内、正文15000字内；最多6份、合计24000字）。手动链接仅作来源标注，不直接抓取；PDF/Word请复制相关正文。手动资料优先于自动搜索，不混用太阳知识库。

资料输入后发送至用户配置的百炼空间。不要上传密钥、账号凭证、私人学生记录或未经许可的全文。项目是本机单用户数据；当前没有多人权限隔离。

## 使用顺序

1. 直接填写自己的问题，默认启用自动来源；也可点示例或展开“我有资料”。两个示例来自NIST与IES公开资料的中文整理摘要，不冒充原文翻译。
2. 点击“生成科普视频”。右侧立即显示真实执行阶段：查资料、讲解、审核改写、复检、卡通规划、视觉检查、AI旁白、字幕与合成MP4；无需重复点击或根据假倒计时等待。也可勾选“这次只准备讲解与脚本，暂不制片”。
3. 默认打开“科普视频”，通过审核后自动制片；完成时进度卡原位切换为播放器，可直接播放/下载。分镜脚本和修改候选默认折叠；“一步步讲清楚”有3—5节完整讲解及理解题。“配套海报（选做）”按需打开SVG预览。
4. “证据与版本”集中显示来源、修改数量、前后差异、复检说明和人工补充建议。自动修订入口放在这里，避免干扰视频观看。
5. 可在“证据与版本”补充自己的建议，再执行自动审核修订。更换资料时复制为新项目，不能偷偷改变旧稿的证据来源。
6. 刷新后从“打开已保存项目”恢复。版本页可查看初稿、修改稿和对应海报。
7. “导出草稿包”包含最新版SVG、离线展示HTML、分镜JSON、完整项目/修订/调用记录、估算时间字幕SRT。导出包含自己的资料，分享前再检查授权与隐私。

## 自动修订的真实边界

- 第一阶段由千问生成事实卡、概念图规格和独立分镜，不是把海报逐字朗读。
- 程序逐条验证`source_id`存在且引文能在该来源正文中定位，验证分镜引用的事实编号存在。它**不证明引文支持该结论**，更不证明资料本身可靠。
- 千问进行语义审核并返回完整修订稿，再次定位引文并调用千问复检。
- 若复检还有问题，可进入第二轮，总共最多两轮，避免无限反复调用。仍有问题则停下交给人，不能宣称已经合格。
- 不通过的候选修改只记录为`proposed_changes`，不覆盖原稿。无内容变化时记录为审核版本，`changes`为空；不伪造修改量。
- 同一请求ID重试不会重新触发模型；并发操作/过期版本被阻止。中途失败保留已有稿件，不自动收费重试。
- 模型仍可能误判。真实测试中，第一次AI复检放过了“统计生成→没有理解”等过度推论，开发者补充审核意见后再次修改。该过程是开发者反馈，不是独立公众评测或专家通过。
- 输出统一标为“AI生成草稿，待人工终审”。视觉检查针对卡通代表帧及结构，仍不是对最终MP4所有帧/语音/科学内容的认证；对象和动作库有限，不是任意主题精细角色电影。

## 模型合规

核对日期：2026-08-31。依据[赛事官网](https://university.aliyun.com/action/tzbjbgs2026)及用户提供的方向2提交模板。基座使用千问，通过百炼调用；方向模板明确也包含Wan。本项目当前更保守地将配置限定为Qwen系列，不自动回退第三方模型。

| 环节 | 实际模型/方式 | 本版接入情况 |
|---|---|---|
| 跨主题生成、审核、修订、复检和资料筛选 | 百炼北京 `qwen3-max`，由QWEN_STUDIO_MODEL配置 | 与早期qwen-plus流程分开；按操作保存调用ID、模型、提示词版本/哈希及Token用量 |
| 图解排版 | 团队Python SVG渲染代码 | 已接入；不冒充文生图模型输出 |
| 图像生成 | `qwen-image-3.0` | 插画媒体实验路线；已出现伪文字与审核漏检，当前默认视频不走此路线 |
| 卡通规划 | `qwen3-max` + 本地对象库 | 将脚本转成对象、标签、关系和运动；非图像模型生成，检查箭头顺序，保留人工反馈 |
| 图像理解 | `qwen3-vl-flash` | 每镜代表帧及对象关系检查，有问题最多修正一次；仍不通过停止合成 |
| AI旁白 | `qwen-audio-3.0-tts-flash` | 通用逐镜旁白；按实际PCM字节计算时长并校验字幕区间，避免异常WAV头破坏时间轴 |
| 视频 | Pillow + FFmpeg本地合成 | 默认程序绘制卡通运动、配音字幕；目标60—90秒，不冒充视频大模型生成 |

接口配置必须是百炼北京HTTPS域名；服务端拒绝其它平台和模型系列。真实调用日志不记录Key。费用仅是本地价格假设下的估算，无法代替阿里云实际账单；70元暂停、100元实付上限不变。

本机若开启VPN的Fake-IP/TUN模式，官方域名可能解析至198.18.0.0/16。默认会拒绝这种保留地址。只有确认本机路由属于自己的VPN后才可设置`RESEARCH_ALLOW_VPN_FAKE_IP=true`；白名单域名、HTTPS证书检查和其他私网拦截仍生效。部署服务器保持false，不要为绕过错误关闭所有地址校验。

模型能力和价格依据[百炼qwen3-max官方说明](https://help.aliyun.com/zh/model-studio/model-qwen3-max)。本地使用7/28元每百万Token的保守高档估算，搜索插件另以账单核对，估算不代表实付。

## 封装版运行

源码开发使用Vite；封装版使用构建好的`frontend/dist`，仅运行一个Python服务，地址为`http://127.0.0.1:8000/`，不需要同时启动5173。

本机可双击`启动封装版.cmd`。启动器先检查已运行版本并复用，不会重复启动，不会盲目结束占用端口的进程；后台启动不额外弹出服务窗口。出错时保留控制台提示，日志位于`.local-logs/packaged.*.log`。

这是“预构建前端＋Python后端”的本地包，**不是免安装EXE**。新电脑仍需Python 3.11+及后端依赖：先在项目根目录创建`.venv`，安装`backend[dev,video]`；按交接教程创建自己的`.env`，建议先Mock。包里不含别人的Key、数据库、原始视频素材或云端知识库。

当前仅支持单个后端worker。不要增加`--workers`，因为启动恢复和任务队列按单进程设计。数据库默认在`artifacts/studio.sqlite3`；设置`SCIENCE_POSTER_DATA_DIR`可更改数据库位置，但媒体当前仍在仓库`artifacts/studio-media`。云端须同时持久化这些内容，完成鉴权限流后才能上线，不能把临时目录当唯一副本。

## 提交前仍需完成

方向2模板要求技术方案PPT/PDF不超过20页，而不是官网总说明的30页；演示视频如有不超过10分钟。需要设计源文件/高清图、科学资料来源、真实调用凭证、代表图与修正对比；程序作品需源码与运行说明。团队名称、报名表两页盖章截图等由参赛团队补齐。

下一阶段扩充跨主题卡通对象与科学过程动作、最终视频视觉/科学复检，再做正式成品验收、提交文档和公网部署。不能把程序动画写成“视频大模型原生卡通动画”或专家验收通过。

## v0.4使用方法与透明边界

1. 新建项目输入问题。千问先写标明“尚未核实”的初步解释，按领域查原始技术文档、标准或科研资料。常见技术概念有MDN/AWS官方目录入口，但没有预写答案：仍须读取原网页并逐字核对。
2. 有依据后生成详细讲解、理解小问题及6—8镜，通过复检后自动继续卡通视频。在“一步步讲清楚”阅读完整解释；海报选做，原文在证据层。
3. 旧检索失败的项目不自动覆盖。点“复制问题，使用新版重新检索”后再生成，旧失败记录保留；新操作会产生调用费用。
4. 不必再点击第二次制片按钮。失败/只生成过脚本的项目仍可手动制作：千问规划卡通→程序绘制→视觉检查→必要时修正→配音→合成；详细候选默认折叠。第二次仍不过关就停下，不无限重试。自动制片要求本轮复检成功，Mock及拦截状态不自动收费。
5. 完成后可播放/下载MP4；配套SVG/详细脚本从草稿包导出。MP4独立下载，不塞入草稿ZIP。媒体绑定具体脚本版本，旧片不覆盖；同版成功不重复做，除非明确记录人工“仍需修改”。再制作可复用同版已完成配音，规划/审核仍收费。默认不额外生成PNG；插画实验路线保留但不作为推荐成品。

安装视频依赖`pip install -e "backend[video]"`，Windows默认使用微软雅黑；Linux需安装Noto CJK或设置`SCIVIS_FONT_PATH`。真实配音按镜头计时，镜内字幕按字数分配，尚非强制对齐。所有成果带预览/待终审标识，不能免除用户科学复核。

接口依据：[千问生图API](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)、[千问语音SDK](https://help.aliyun.com/zh/model-studio/cosyvoice-tts-python-sdk)、[联网搜索](https://help.aliyun.com/zh/model-studio/web-search/)。资料来源允许其他机构；运行的生成模型仍仅使用百炼千问。

资料链接：[NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1)、[IES学习指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。模型结构化输出依据[百炼官方说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。
