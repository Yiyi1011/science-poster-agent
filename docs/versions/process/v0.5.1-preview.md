# 制作过程 v0.5.1-preview

本版把“用户只需提问”落实为默认工作流：千问先给未核实的初步解释，再自动扩展检索官方/研究来源、逐字定位摘录、生成通俗讲解与6—8镜脚本、最多两轮审核修订，审核没有证据阻断项时立即进入卡通视频制作。用户不再承担提供论文或证据的前置责任。

## 本版修复

- 模糊基础概念不再只取搜索首页碎片；以“token”为验收题，千问会识别其语言模型、数据安全与访问令牌等常见含义，读取IBM官方说明及RFC原文，再选择与公众问题相符的证据。
- 每次“使用新版重新检索”保存独立研究尝试，旧资料、旧稿和旧视频不覆盖；审核提出可修问题却漏写修订稿时，增加一次有上限的实际改稿调用。
- warning只作为人工终审提醒，不再阻止默认视频；证据缺失或科学边界错误仍会停止制片。
- 旧版/中断版的手动制片按钮成为恢复入口；正常新问题在左侧提交后，右侧直接显示真实进度并自动切换为播放器。
- 归档代替直接删除。现有20个重复/相似失败项目已在私有SQLite中归档，选择器保留6个代表项目；归档数据可恢复。
- 完整句字幕保持同一时间块，且中文句号、逗号等不再孤立到下一显示行。
- Windows启动器优先识别`backend/.venv`，启动前检查Python依赖、FFmpeg、中文字体和真实百炼配置，并在等待时显示状态。
