# 制作过程 v0.5.4-preview

本版为作品管理界面的归类与整理：已保存项目自动分成“案例”（已生成过视频或示范主题）与“我的问题”（其余提问），每行提供收藏与删除按键。收藏项目组内置顶；删除为软删除（数据完整保留、可恢复）。

## 本版新增

- 列表标记：`GET /api/studio/projects` 每项新增 `has_video` 与 `favorite` 两个布尔字段；`has_video` 依据媒体记录（state=succeeded 且存在 video 文件）判断，不依赖前端猜测。
- 收藏：新增 `project_favorites` 表与 `toggle_favorite`（切换返回新状态）；路由 `POST /api/studio/projects/{id}/favorite`，项目不存在返回 404。
- 删除：路由 `DELETE /api/studio/projects/{id}` 复用归档机制（`archive_project`）——列表消失但数据库与媒体文件完整保留，可经 `list_archived_projects`/`restore_project` 恢复，不误删任何付费产出。
- 前端分组列表：已保存项目从下拉框改为分组列表——“案例 · 已生成视频”在上、“我的问题”在下，收藏项组内置顶；每行提供打开、★ 收藏（点亮反馈）、✕ 删除（confirm 确认；若删除的是当前打开项目则回到新建界面）；新增对应样式。

## 验证

- 后端完整测试：187 项全部通过（新增 1 项 API 回归：无视频不标记 → 收藏切换 → 有视频后标记 → 删除后列表消失但归档可恢复 → 不存在项目 404）。
- 前端生产构建通过（`tsc -b`）。
- 服务器重启后真实列表验证：全部已保存项目带正确标记（天空蓝、间隔复习、重复复习等已出片项目 `has_video=true`；8 个重复的“为什么天空是蓝色的？”测试项目未标记，等待用户用新删除键清理）；收藏切换 `{"favorite":true}`→`{"favorite":false}` 与删除 404 实测通过。

## 边界

- 这是制作过程候选，不创建 `final/` 标签。公众试听、领域人员科学终审、正式名称/团队/盖章报名表和提交PDF逐页检查仍未完成。
- 删除是软删除：对用户是“删除”，对系统是归档，误删可恢复。
- 政治敏感话题仍不进入自动制片；明显危险或无法核实的断言会降级为说明而非默许。
- 公开部署、云资源创建与最终提交包仍需负责人另行确认。

## 同日修订：按用户意见移除收藏功能

用户实测后认为收藏“没什么用”，要求移除：删除 `project_favorites` 表、`toggle_favorite`、`POST /projects/{id}/favorite` 路由与前端 ★ 按键及置顶排序；已保存项目保留折叠栏形式与删除按键。列表字段只留 `has_video`。后端 187 项测试通过，新构建包实测无收藏代码残留（LOGO 054）。
