# 制作过程 v0.4.2-preview

## 本版解决的实际故障

用户完整观看首条跨主题卡通片后发现：虽然视频有6段不同旁白，画面底部却一直停留在第一句字幕。进一步检查发现，百炼Qwen TTS返回的WAV文件头把数据区长度写成异常大值；旧合成器相信文件头，算出了负数和数小时长的字幕区间。之前的浏览器自动检查只验证了“能加载、能播放、总时长正确”，没有在多个时间点读取烧录字幕，因此漏掉了这个缺陷。

用户同时要求：点击左侧生成后，右侧立即呈现检索、审核、自动修订、卡通规划、旁白、字幕与合成进度；完成后原位显示视频，不再让大量修改按钮挡在视频前。

## 修复与交互

- WAV时长改为按实际读取到的PCM字节数、声道数、采样宽度和采样率计算，不再信任异常的数据块长度字段。
- 合成前逐条验证字幕时间轴：禁止负时间、倒序、零长度及超出视频末尾；异常时停止，不生成看似成功的坏视频。
- 复用既有6镜画面和6段旁白零模型调用重合成，原错误MP4不覆盖；新旧文件、原因和时间写入程序修正记录。
- 右侧新增真实进度制作台。初始检索阶段没有草稿时也能看到当前状态；制片阶段展示最近6条实际事件，完成后自动切换播放器。
- 同一脚本有成功与失败制片记录时，优先显示最新可播放成功成片，旧失败记录折叠保留。
- 人工补充建议、修改前后对比和重新组织按钮移至“证据与版本”，视频页只保留成片、下载、必要状态和折叠检查痕迹。
