## 录制设置

- 画面：1920×1080，浏览器缩放90%—100%，仅保留应用标签页；关闭收藏栏、通知、账号头像和控制台。
- 操作：录制前先在本地完成一次太阳生成，避免现场网络波动；真实等待片段后期加速到2—3秒，但字幕必须说明“已加速”。
- 音频：AI旁白＋烧录字幕；背景音乐可不使用，避免版权与人声遮挡。
- 隐私：不打开`.env`，不展示请求Header、完整API Key、本机用户名或控制台个人信息。
- 备份：保留原始录屏、无字幕母版、旁白WAV、SRT和最终MP4；最终视频上传夸克网盘后再写入提交文档。

## 录制前门槛

1. 用户先确认现有太阳旁白中HF、GNSS、CME读音。
2. 正式作品名确定后替换片头与旁白中的临时名称。
3. 公网应用未部署前可以录制本地演示，但提交前仍需独立验证公开链接。
4. 若任何模型调用失败，演示使用已保存结果，不在录制中反复付费重试。
