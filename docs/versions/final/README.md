# 最终交付区（尚未发布）

本目录与 `../process/` 制作说明分开。当前没有最终版代码标签或交付包。

进入最终交付前至少完成：

- 普通用户不依赖预设主题的全流程测试，失败与证据不足有明确提示。
- 公众语言和科学正确性人工终审；自动审核不能替代专家审查。
- 声称支持的海报、动画、配音、字幕、自动修正功能分别有真实验证。
- 与方向2提交模板逐项核对，材料不超过20页，补齐正式名称和报名材料。
- 依赖安装、启动、配置、密钥排除、数据备份和恢复经过验证。
- 模型调用符合赛事要求；保留脱敏调用凭证与版权/来源说明。
- 如果提供公网访问，另外完成鉴权、限流、费用保护、持久存储与访问期安排。

满足后才创建 `final/v1.0.0` 标签和最终交付Release。本目录用于最终清单与验收报告，不存放密钥或私人账单。
