# 制作过程 v0.4.5-handoff

本检查点不改变v0.4.4的运行功能，目的是让Claude中接入DeepSeek API的下一位开发者可以在不依赖聊天历史的情况下安全接手，并在之后把项目交回原开发者继续处理。

新增`docs/NEXT_STAGE_EXECUTION_BRIEF.md`作为唯一任务入口。文档将下一目标分为：任意科普问题到完整视频、主工作台UI优化、Windows封装与参赛候选验收；分别注明主要代码文件、测试位置、运行成果、文档和最终候选包的存放规则。

生产运行仍只使用阿里云百炼Qwen系列。DeepSeek与Claude仅用于开发和审查。旧作品、SQLite、媒体、证据、旧标签和密钥均不得覆盖或提交。

建议从`process/v0.4.5-handoff`建立`dev/general-science-video-v0.5`。若后续改动失败，在新目录检出本标签，以Mock运行构建和测试后再恢复；不要在脏工作树中强制切换。
