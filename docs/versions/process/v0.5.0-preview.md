# 制作过程 v0.5.0-preview

本版完成简报第6节的通用闭环：“任意合理科普问题→自动检索权威资料→通俗充分讲解→6—8镜→审核修订→AI旁白与完整句字幕→可播放MP4”，并在四道跨主题验收题上端到端跑通（其中三道为真实付费的百炼调用）。

## 与 v0.4.5 相比的变更

- **JSON 结构化输出加固**（`studio_structured_output.py`）：字符串感知的括号扫描、拒绝多个歧义 JSON 对象、只修复 trailing comma 等安全格式问题、容器范围内字段别名修复；修复结果带说明，供审核留痕。
- **确定性降级**（`studio_fallback.py`）：千问规划与一次结构修复均失败时，按已审核来源组织本地 6 镜模板初稿，明确标注 `fallback` 与“待人工核实”，绝不伪装成模型规划成功（简报 §6.4.6）。
- **检索后备**（`studio_research.py`）：按领域配置后备官方页（NASA/IES/WHO），搜索异常或来源不足时仍能取到可定位原文；关键词拆分/扩展只在初始检索不足时补充，控制调用次数。
- **来源选择部分支持规则**：来源只能支撑部分核心主张时仍应被选中并如实写 gap，后续审核逐条核对，不能靠模型知识补写证据。
- **SQLite 锁加固**（`studio_store.py`）：WAL 模式 + `timeout=30`，应对 WPS 云同步对目录的间歇性文件锁；验收驱动脚本只走 HTTP，不直读数据库。
- **双向交换箭头渲染修正**（`studio_cartoon.py`）：exchange 关系改为同一水平线两端各画箭头（◄──►），流动圆点分上下按方向对向运动。此前画在两条错开水平线上的箭头被视觉检查读成单向/歧义，导致间隔学习第 5 镜两次被拒。
- **媒体完整性独立复验**（`studio_video.py::verify_media_output`）：ffprobe 时长/音轨 + 0.25/0.5/0.75 秒三点抽帧。
- **新增 HTTP 验收驱动**（`scripts/run_studio_acceptance.py`）与 v0.5 测试（`tests/test_studio_v05.py`，15 项）。
