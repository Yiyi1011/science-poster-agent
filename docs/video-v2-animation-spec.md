# 太阳爆发卡通科普动画 v2 制作标准

## 定位变化

- v1：静态海报推拉＋海报内容旁白，保留为技术预演和过程证据。
- v2：独立的普通公众科普动画，目标不是“把海报念一遍”，而是用动作、时间和因果顺序帮助理解。
- 应用操作演示视频与科普动画分开制作：前者证明AI应用如何工作，后者证明最终传播作品质量。

## 公众语言规则

1. 先说日常对象，再给专业名词。例如先说“卫星导航定位”，必要时片尾再标注GNSS。
2. 每条字幕只表达一个意思，推荐不超过18个汉字；专业缩写不连续出现。
3. 用“可能、在某些条件下、主要影响”表达边界，避免“一定、全部、立刻瘫痪”。
4. 比喻必须明示是帮助理解的隐喻，不能把卡通角色当成真实物理结构。
5. 不用“电离层D层、磁重联”等术语解释另一个术语；需要深入内容时做可选的延伸卡，而不是塞入主线。

## 动画风格

- 2D扁平卡通，轮廓圆润、角色友好，太阳、三位信使和地球保持一致造型。
- 深蓝宇宙底色配黄色、橙色、青色三类速度编码，但不照搬海报版式。
- 镜头以出发、追赶、抵达、影响条件提示卡和预警接力为主要动作；条件提示不能画成实体闸门，不用连续推拉静态长图。
- 不生成片内关键文字。时间、短字幕、来源和条件标签由程序后期叠加。
- 不出现城市爆炸、卫星坠落、全球断网等夸张灾难画面。

## 实现路线

> 2026-08-31进度：实际采用`storyboard-v003.json`的305字脚本。单用户已认可卡通方向；7段千问旁白已生成，实测61.76秒，经镜头留白调整为67.417秒有声试听版。原84秒无声分镜保留。下面的5人测试和模型关键帧审核仍是待办，未因单人方向认可而算作完成。

1. 根据`storyboard-v002.json`制作7张角色设定/关键帧，每张绑定source_ids。
2. 先用本地平移、分层和角色运动做低成本动态样片，确认叙事节奏。
3. 进行5人快速理解测试：看完后能否回答“三种信使、三个时间尺度、强耀斑是否必然造成强地磁暴”。
4. 修订脚本后再生成AI旁白与短字幕；缩写只在片尾术语卡出现。
5. 若本地动画不能满足角色动作，再核对Wan模型可用性和单价，按镜头单独生成；调用前重新确认视频预算。
6. Qwen-VL检查关键帧的一致性、灾难化倾向和错误物理关系；事实问题仍由人工裁决。

## 成品验收

- 不看海报也能独立理解；画面与旁白互相补充，不是逐字重复。
- 7个场景均能指出学习目标和来源编号。
- 字幕移动端可读，单屏不过载；角色外观和三类颜色前后一致。
- 观众不会得出“所有通信都会中断”或“强耀斑必然造成强地磁暴”的错误结论。
- 保存关键帧、动画提示、模型名、脱敏request_id、失败镜头、人工修改和最终版本。
