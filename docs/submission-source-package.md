# 评委查看用核心代码附件规范

提交方式：源代码 ZIP 上传夸克网盘；提交材料同时附 GitHub 仓库链接。两者对应同一个最终 Git 提交和 `final/v1.0.0` 标签。

## ZIP 顶层必须包含

- `README-评委请先看.md`：项目作用、三步体验、在线地址、主要模型、核心创新、已知边界。
- `SOURCE-MANIFEST.json`：版本、commit、文件数、生成时间、ZIP SHA256 和排除项声明。
- `backend/`、`frontend/`、`scripts/`：核心源代码、测试和打包脚本。
- `Dockerfile`、依赖锁文件、`.env.example`：可复现运行配置；示例文件不得含真实密钥。
- `docs/CODE_MAP.md`、`VERSION_NOTES.md`、`docs/versions/`：代码导航和制作/最终版本区分。
- 精选、脱敏的测试报告与代表性成片说明；大体积视频可另放成果目录，不重复塞入源码 ZIP。

## 必须排除

- `.env`、API Key、AccessKey、Cookie、控制台登录信息。
- `scivis-data/`、SQLite 数据库、私人问题、未脱敏日志、原始模型响应。
- `.git/`、`node_modules/`、虚拟环境、缓存、构建临时文件和重复过程压缩包。
- 未获授权的论文全文、私人材料和被拒绝的视觉候选。

## 最终检查

1. 从 `final/v1.0.0` 的干净工作树生成，而不是从任意制作目录复制。
2. 解压到全新路径，按 README 完成前端构建、后端测试和容器/在线地址检查。
3. 搜索 `sk-`、`DASHSCOPE_API_KEY=`、`AccessKey`、`.env` 和常见密钥格式，结果必须只有无值模板或说明文字。
4. 计算 ZIP SHA256，并把完整值同时写入 manifest、提交文档和夸克网盘说明。
5. 检查夸克分享链接无需登录即可下载，GitHub 标签链接可访问；提交前再次扫描二维码和超链接。

正式文件名暂定：`科普视频智能生成工作台-v1.0.0-源代码与说明.zip`。作品正式名称确定后再统一替换，不覆盖过程包。
