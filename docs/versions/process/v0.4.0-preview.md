# 制作过程 v0.4.0-preview

## 要解决的问题

“API是什么”被偏自然科学的来源范围挡住。用户要求基础概念也能回答，科普要通俗而且充分；随后明确默认输出视频，海报选做，画风/节奏参考已认可的太阳动画。

## 本版改动

- 千问先给标明未核实的初步解释，再按technology/science/education/health/general查资料。初步回答与sources完全分开，不能成为自己证明自己的引文。
- 技术类增加原始文档/标准站点。常见概念从MDN/AWS目录取真实网页，不是把API答案写死；保留HTTPS、DNS、域名、大小和重定向限制。
- 优先main/article正文，记录筛掉/读失败/摘录失败的原因。最多两次搜索、六次原文访问、四份成功正文、三份摘录；没取得有效资料仍不生成可提交作品。
- 新增3—5节详细讲解与理解小问题，海报仍可快速阅读。新生成/修订结构要求6—8镜，老3镜项目仍能查看。
- 通用检查增加安全保证/具体实现的无依据推断，也注意否定句不能误判为承诺。AI语义审核仍可能漏检，尤其“类比过度推断”，不声称规则可保证科学正确。
- 默认成片：通过脚本复检后自动继续千问卡通规划→程序绘制对象与运动→Qwen-VL逐镜检查→最多一次修正→千问旁白→本地合成MP4。目标60—90秒，按实际配音加适量停顿，不剪掉讲解凑时长；API实测6镜68秒。
- 前端以视频为首页结果，脚本和审核细节折叠；完整解释、理解小问题、证据各有入口。海报仅选做预览/导出；默认制片不额外生成PNG海报。保留仅做文本脚本选项。
- 实验路线：Qwen-Image逐镜插画＋缩放镜头＋旁白合成，已实测50.56秒，但多处伪文字被视觉模型漏检，不作为当前推荐成片。原候选、问题及人工评价保留，不冒充已经解决。
- 媒体按项目/脚本版本绑定，请求幂等、同版成功不重复收费；修改脚本与生成媒体互斥；中断不自动重做。接口只允许读取清单内文件，不能借媒体路径读.env。
- 修正图片调用已成功但下载失败时漏记估算费用的问题，费用在下载前入账。

## 仍然不是最终版

卡通对象、连线和动作由代码绘制，千问规划和配音，不是视频大模型原生角色动画。对象库有限，复杂轨道、实验过程等仍需扩展专用动作/几何表达；不能保证任意问题都充分可视化。镜内字幕按真实语音时长和字数分配，不是逐字强制对齐。没有公网部署或专家/公众验收。

## 实测与问题留痕

- API仅输入问题，取得AWS公开API说明，生成详细讲解和6镜。现有来源候选部分来自模型提出URL后真实读取，并非都由搜索返回；候选未读取或摘录不匹配不会作为证据。
- 月相取得NASA公开页面并生成6镜，但开发者仍发现类比和适用范围过度推断，保留反馈/旧稿；未作为正式成片验收。
- API卡通首版已通过自动链路并得到68秒MP4。开发者检查第四镜发现手机→数据库→API的箭头顺序误导，模型曾漏检；加入通用对象顺序检查，并在新任务中传入有出处的人工反馈。旧视频不覆盖，同版配音可复用。不能把这次人工发现写成模型自发发现。
- 无资料、失败、复检拦截、Mock模式不会自动调用收费制片；相同请求ID不重复启动。人工标记需改的成功媒体可明确再制一次，旧文件保留。
- API再制片复用六条同版旁白，第三镜发生一次模型修订与复检；实际两段解释变更可对照，检查要求不等于全部落实。入场遮挡标签另以程序动效修正、零模型调用重编码，旧视频保留。
- 144项后端测试、3项旧太阳动画测试和前端构建通过；隔离Mock浏览器7项通过。真实68秒视频播放/下载、手机宽度、选做海报及API/月相SVG边界通过。没有完整科学、听感或公众认证。

源码、私有作品版本、费用档案是不同内容。源码不含.env及私有数据库；完整媒体与调用记录另行脱敏交接。参见[工作台指南](../../studio-guide.md)和[版本导航](../README.md)。
