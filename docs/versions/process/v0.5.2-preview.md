# 制作过程 v0.5.2-preview

本版把作品做成“成品”而不是“流程演示”：页面与视频不再出现制作话术，顶部案例并入已保存项目入口；同时消除“资料不够无法生成视频”的死胡同——证据不限于论文，政府、大学、专业机构、标准与权威科普页面都算可核对的证据，普通科普问题默认即可自动出片。政治敏感内容仍阻止，仅对明显危险或无法核实的断言降级说明。

## 本版修复

- 主页面、导出与播放器文案全部改为成品口吻（“SCIVIS · 科学可视化”“来源可核对 · 修改有记录”“视频制作完成”）；“制作说明/待终审/流程演示/不模仿模型”等幕后话术移除，来源与程序痕迹只保留在“证据与版本”中。
- 顶部标题栏的两个示例案例（太阳动画/太阳分镜）并入选择器的“示例项目”分组，不再作为独立页面。
- 检索防死胡同：
  - 浏览器验证页（reCAPTCHA/访问验证）与登录墙页面在抓取时直接判为不可用，不再被误记为“原文已提取”。
  - 教育领域后备入口增加 OpenStax 心理学教材（复习/间隔/记忆/大脑多术语匹配），与 IES 实践指南互为补充。
  - 机制类问题（为什么/如何工作）筛选时同时摘录“做法句”与“效果/机制句”；第一轮漏掉机制段时，最多再调用一次有上限的二轮筛选（逐字原文，不程序化改写）。
- 审核更稳：
  - research_gap 为硬边界：明确机制证据缺口时，不得用模型常识补写大脑/巩固/遗忘曲线/神经/长期记忆等机制句。
  - 无来源的具体数字/时间表（第X天、X%、X周等）阻止出版；旁白只能讲来源确认的范围（如“几周甚至几个月”）。
  - 最后一轮修订被拒但本轮已有通过版本时，沿用已通过版本继续制片并记录拒绝，不再整体阻塞；被拒候选永不发布。首轮即被拒且无已通过版本时仍整体阻止。

## 真实验收：为什么重复复习要隔一段时间

- 项目：`6c135d87-2910-4886-9a44-712ff4f478f4`（私有运行数据，不提交Git）。
- 修复前：同一问题 4 次真实重跑均被阻止（PMC reCAPTCHA 假正文、机制段未被选中、OpenStax 未匹配、第二轮审核振荡、服务器加载旧代码）。
- 修复后：研究阶段真实抓取 IES 实践指南与 OpenStax 教材，千问二轮筛选如实保留“未解释间隔影响记忆巩固的神经机制”的缺口（不伪造机制）；审核通过无阻断项；自动进入制片。
- 媒体首次因一次瞬时 ConnectError 失败（素材保留），重试后成功：68 秒 1280×720 MP4、12 个完整句字幕、6 镜 Qwen-VL 检查全 pass、6 段 Qwen TTS 配音；字幕明确写“指南没说具体隔几天最好”“它只确认：拉开时间复习关键内容，是一种有效的教学安排”——不虚构时间表与机制。
- 完整性：媒体完整性检查 ok，18 个文件（6 图、6 音频、合成音轨、MP4、SRT、3 抽帧、清单）落盘；MP4 结构可解码。
