# 制作过程 v0.3.0-preview

## 为什么改

用户反馈原海报直接展示论文式事实卡，术语过深、图解只有标签；三镜故事不够丰富。优化针对整个跨主题生成链路，不是为AI案例写死一份答案。另增加“只提问题找资料”和清楚区分代码版本的需求。

## 本版代码变化

- `StudioDraft.public_poster`：独立的公众短句、生活情境、必要提醒和图解节点。每项都关联事实编号，证据页仍保留原文。
- 通用编辑规则：新稿6—8镜，覆盖提问、例子、机制、边界和收束；不得靠重复或无依据事实凑镜数。
- 生成→结构核对→千问修订→复检仍最多两轮。拒绝的候选保留痕迹但不覆盖原稿；下一轮针对该候选的问题继续修改。
- 新版SVG：带说明和程序图标的节点、短句解释、来源脚注；长英文正常按词换行。旧版本继续使用原布局，可对比。
- 自动检索：百炼Qwen联网搜索→白名单站点原文读取→千问选段→逐字定位→独立资料快照→生成。找不到原文时不使用模型自带知识凑依据。
- 原始用户输入、检索快照、每轮作品分别保存；手动资料优先，自动来源按项目隔离。
- 输出结构不合法时最多一次模型结构修复，错误只返回字段路径，不泄漏响应或密钥；删节引文按显式标记逐片段、按原顺序定位。
- 兼容图解标签以公众节点为准自动同步，单独标记为程序排版修正，不冒充AI科学修订。
- 可选从原始证据重新组织整篇表达，仍保留旧稿；这能避免不断沿用旧稿的错误例子。
- 新工作台使用百炼`qwen3-max`，早期流程的`qwen-plus`配置不改动。价格按保守高档估算并保留原预算闸门。
- GitHub增加版本导航、制作/最终说明分区和代码文件索引。

## 怎么运行

按[工作台指南](../../studio-guide.md)安装依赖并构建前端，再用根目录“启动封装版.cmd”。只在本机访问 `http://127.0.0.1:8000/`。

新建项目，写问题即可；自动检索默认开启。已有资料可以展开“我有资料”并粘贴摘录。旧项目不会自动覆盖；用“再次自动审核与修订”形成新版本。

## 真实边界

- 这是制作预览版，不是最终交付版；通用视频目前仍是分镜和无声预演，不是任意主题自动生成完整有声卡通MP4。
- 自动检索是首批站点的公开HTML检索，不是全网论文全文数据库；PDF、付费墙、登录页、脚本渲染正文可能无法读取。至多两次搜索、十个候选、四份原文、三份入选摘录。
- 白名单和原文匹配只提高可追溯性，不保证来源质量、摘录涵盖全部争议或AI结论正确。人工终审仍必需。
- 失败来源快照保留，不会在重复点击时暗中重复检索扣费。需要更换问题或手动补料时复制为新项目。
- 只使用当前配置的百炼千问模型，无第三方模型回退；搜索插件费用需以账单核对，本地文本估算不是实付。
- 无公网部署，没有把开发主分支标为最终版。

## 接口依据与过程证据

联网搜索采用[百炼官方文档](https://help.aliyun.com/zh/model-studio/web-search/)的DashScope原生接口，以取得来源元数据。OpenAI兼容方式的搜索来源参数支持与此不同；实现不从模型回答正文猜测URL。

完整本地调用/作品记录位于被Git排除的 `evidence/studio-v030/`，交接时需单独脱敏导出。模型复检有漏检，AI案例还接受了明确记录的开发者科学复核意见；不得将这些开发者反馈写成自主无人工成功率。
